# Responsive viewport vertical padding tokens

The viewport vertical padding tokens in Milo's `libs/c2/styles/deps/tokens.responsive.*.css`. Responsive tokens have one set per breakpoint: sm applies at every width, and md, lg and xl from the width shown.
