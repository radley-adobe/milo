# Semantic button color tokens

The button and icon button color tokens in `tokens.semantic.light.css` and `tokens.semantic.dark.css` in Milo's `libs/c2/styles/deps/`, the `--s2a-color-button-` and `--s2a-color-iconbutton-` tokens. Each section has the button or the icon button tokens of one style. Semantic colors have a light and a dark set.
