# Semantic tokens

Every token in Milo's `libs/c2/styles/deps/tokens.semantic*.css`, in the groups those files use. Values are resolved. When Milo declares a token as another token, the description shows that reference.

Semantic colors have a light and a dark set.

Right-click a token to see which C2 blocks read it in their CSS.

))}
